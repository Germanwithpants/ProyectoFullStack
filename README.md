En esta etapa de proyecto ya definimos los servicios basicos para una pagina web, utilizando html,css,js separando por carpetas para una mejor organizacion por ejemplo tenemos img/src, tenemos js/scripts.js.
Contiene index como pagina principal, admin para pagina del admiinstrador para agregar productos, modifcarlos, ver los usuarios que compran, un dashboard.
Y por ultimo un Login que diferencia el usuario como administrador y usuario cliente. Dependiendo el usuario que ingrese redirigira a una pestaña correspondiente.
La pagina vende productos de ropa, con un filtro, un buscador por palabras clave.
